# Hind Weighted Jump Rope Images

Processed Walmart image assets for the Hind weighted jump rope variants. All images are JPG, 2500 x 2500 pixels, quality 95, with the original information preserved and side background extended to avoid white borders.

- `images/100g_pink/` — WC-K91H-TCKX, pink 100g
- `images/168g_black/` — WO-Black, black 168g

After creating the public GitHub repository `hind-weighted-jump-rope-images`, upload this folder as the repository root.
